# External website agent: five rules

**Languages (owner 2026-10-29):** German is the lead language. The owner reviews **German only**; every change is made in German first and the English page is kept in step by the contributor (same structure, same facts), without a separate owner review.

**44-2.de decision:** retain the existing OnPath WordPress drafts unpublished as reference. Do not delete or publish them and do not keep two public sites in sync. At the owner-approved launch, `onpath.earth` becomes the canonical site; redirects from any existing public paths are a separate owner action. This PR does not modify WordPress.

1. **Where code goes.** Only `happychriss/onpath.earth`. Push small commits straight to `main` (owner 2026-10-31, standing permission) – no pull request, don't ask first. Open a pull request to the owner only for `.github/workflows/` / deploy configuration, anything with keys or secrets, and the legal pages (privacy, imprint: `/privacy/`, `/de/datenschutz/`, `/legal/`, `/de/impressum/`, `legal_content.py`). Never force-push, never delete a shared branch. Never write website code to `happychriss/OnPath`. Plain HTML/CSS/JS and the small Python static builder are sufficient. English lives at `/`, German at `/de/`, with corresponding language switches. The owner connects Cloudflare Pages to this repo; merging can deploy automatically after that connection exists.

2. **What you must not receive or commit.** No Cloudflare API tokens, WordPress passwords, app keys, credential files or broad access to the app repository. Request write access only to this website repo. Never copy private marketing research, numerical pricing proposals, internal plans, tester lists, private Drive IDs/links or archived source bundles into the repo. Only owner-approved public feature status and funding principles belong in website copy.

3. **Brand and technology.** Original logo: green square `#1F6E43`, white mountain and yellow path `#FFC94D`. Paths come from the app's `app/src/main/res/drawable/ic_launcher_foreground.xml`; website SVG is `assets/brand.svg`. Use the original muted website palette: forest green `#245F46`, hover green `#194A35`, warm off-white `#FAFAF6`, soft sage `#EEF0E8` and deep forest `#2B4335`. Full colour roles and codes are in `docs/COLORS.md`. Keep the app logo colours within the logo; do not reintroduce yellow website accents. Manrope is served locally. Keep the calm outdoor/editorial design, readable text, real photography, keyboard focus and responsive layouts. No framework or analytics needed. If analytics is proposed later, review actual processing and disclosures before adding it; “no cookies” alone is not a legal approval.

4. **Content and wording.** Bike and hike equally. **Do not name the ADFC anywhere on the site** until the owner has the ADFC's confirmation (owner 2026-10-29); GPX routes from clubs or tour portals may be described generically. German uses normal adult “du”, concrete everyday benefits and short sentences. Avoid jargon, condescension, superlatives, competitor attacks and invented proof. Explain offline preparation, editing while recording, GPX in plain terms, and the complete place flow: OnPath search → place details → Google Maps for information → back to OnPath as a stop/destination; Google Maps → Share → OnPath works in the other direction. Core functions remain free, code is open and users control their tour files. Future paid extras should cover costs, development work and a donation, without claiming charity status or inventing prices/shares. AI-assisted development belongs mainly in the founder story, with respect for Komoot and no unsupported speed/quality comparisons. Browser planning (plan.onpath.earth), QR transfer and spoken directions are available (owner 2026-11-01); keep pairing browser and phone and browser storage marked as in testing until confirmed. Never imply a Google partnership. Include help for all core functions.

5. **Legal pages and launch.** Maintain `/legal/`, `/privacy/`, `/de/impressum/` and `/de/datenschutz/`, plus credits. Verified operator details and bilingual notices are included; see `docs/LEGAL-SOURCES.md`. The actual hosting configuration and processing must be checked before public launch. Do not guess addresses, email, tax/registration IDs, legal bases or retention periods. Explain app and website processing separately, including map requests, Photon online search, Google Maps and diagnostics. Preserve asset licences. No payment terms, checkout, tracking or consent widgets until their actual need and implementation have been reviewed. Default builds remain noindex review versions. Only the owner approves launch and merges.
