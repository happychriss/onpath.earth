# OnPath website colours

The website uses the original, muted outdoor palette from the first saved German design. The original stylesheet is restored verbatim, with only the logo sizing and bilingual-navigation support retained from the later version. Both languages use the same stylesheet. Content, legal notices, photography and font remain unchanged.
